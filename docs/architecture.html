3. Data Flow

Global filters drive every request. Raw responses land in ref()s; everything rendered is derived through computed().

  1. User changes a filter in FilterBar.vue — bound to shared refs in useFilters.js (Time Period, Warehouse, Category, Order Status).
  2. View watches filters and calls a method on api.js, which serialises non-all filters into query params.
  3. axios issues GET to http://localhost:8001/api/* across the CORS boundary.
  4. FastAPI handler reads the relevant in-memory list from mock_data, runs apply_filters() / filter_by_month(), and returns Pydantic-validated JSON.
  5. Response stored in a ref (e.g. allOrders, inventoryItems); computed properties derive KPIs, chart series, and table rows reactively.
  6. Vue re-renders only the DOM bound to changed computed values.
FilterBar → useFilters refs → View watcher → api.js → axios → FastAPI → apply_filters() → mock_data lists
← Pydantic JSON ←  ref().value = data  ← computed() ← template render
